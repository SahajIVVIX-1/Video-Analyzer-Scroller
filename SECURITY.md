# Security Policy

## Supported Versions

Currently, the master branch is the only supported version. Since this repository is a collection of standalone utilities and scripts, there are no long-term support release branches.

| Version | Supported          |
| ------- | ------------------ |
| master  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover any security vulnerabilities or have security-related concerns about this repository, please reach out directly by opening an issue on this repository and tagging it as `security`, or contact the maintainers directly depending on the sensitivity of the issue.

We appreciate your efforts to responsibly disclose your findings, and we will make every effort to acknowledge your contributions.
